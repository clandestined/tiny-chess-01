# tiny-chess-01

A chess engine in 4 KB of Python for the make.fun tiny-chess-01 bounty: negamax alpha-beta with iterative deepening, transposition table, quiescence search, and MVV-LVA + killer move ordering. Deterministic: a fixed node budget per move, no clock reads.

Run it with `python3 main.py`. It plays through the make.fun env at `MAKEFUN_ENV_URL`.
