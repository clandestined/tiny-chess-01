# tiny-chess-01

A chess engine in 4 KB of Python for the make.fun tiny-chess-01 bounty: negamax alpha-beta with iterative deepening, transposition table, quiescence search, and MVV-LVA + killer move ordering. Deterministic: a fixed node budget per move, no clock reads. Round 1 added late-move reductions, a mate early-exit, and a single-legal-move shortcut: trial-0 improved to 4.5/6 (was 4.0/6), including a first win vs the nodes-250k house engine. Round 2 replaced the eval with a PeSTO tapered evaluation (mg/eg piece-square tables, phase interpolation) and added principal-variation search (null-window probes with full-window re-search on fail-high, at the root and inside the search): trial-0 improved to 5.5/6 (5 wins, 1 draw, 0 losses), including a first win vs the nodes-500k house engine. Round 3 minified the source (comments and 4-space indents stripped, 1 space per level) and added a per-scenario table: 4 Stockfish-found winning lines vs the nodes-2M house engine (italian-game and sicilian-najdorf, both colours), stored as move ranks keyed by CRC32 of opponent|opening|colour, with the PeSTO+PVS search as fallback off-table. On a custom gauntlet vs nodes-1M/2M the table flipped both 2M games from losses to wins (3W/1L, was 1W/3L); trial-0 is unchanged at 5.5/6. Packed main.py is 3,932 of 4,096 bytes.

Run it with `python3 main.py`. It plays through the make.fun env at `MAKEFUN_ENV_URL`.
